# CarBrain

Ein Prototyp für Autobesitzer:innen ohne viel technisches Wissen – Fahrzeugprobleme
verständlich einschätzen, Wartungen im Blick behalten und Reparaturkosten organisieren.

⚠️ **Wichtig:** Das ist ein Prototyp / MVP, keine fertige, veröffentlichungsreife App.

## Lokal starten

Voraussetzung: [Node.js](https://nodejs.org) (Version 18 oder neuer).

```bash
npm install
npm run dev
